# Open items (moved to beads)

The backlog moved to beads on 2026-10-16. Beads holds all work still to do and all work in flight, with the label
`site`. The rules are in the parent folder's CLAUDE.md, "Tracking work in beads".

Older documents cite an item as `open-items.md, "<name>"` or by its group ("Foundations", "Milestone 1"). Each item
kept its name as the issue's title, and its group as a label:

- `bd search "<name>"` finds an item.
- `bd list -l site,milestone-1` lists a group. The groups' labels: `foundations`, `milestone-1`, `offline`,
  `feedback` (the owner's feedback of 2026-10-10) and `position` (Hedge School's place).

The last version of this file is in the Git history.
